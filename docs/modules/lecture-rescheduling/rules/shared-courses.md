# Shared courses

- **Type:** rules
- **Module:** lecture-rescheduling
- **Status:** review
- **Owner:** ishanKulkarni13
- **Last updated:** 2026-10-27

A shared course is a course whose students come from several divisions. **PAS** is a regular theory lecture of this kind, covered by the CR. **FCTC** runs fully online.

- **The "shared-course students busy" conflict check is skipped in the first version.** Shared courses are treated like ordinary division lectures.
- No student lists are read from the ERP, so students of other divisions are not looked up for notifications either. This limit is accepted for the first version and may be revisited.
