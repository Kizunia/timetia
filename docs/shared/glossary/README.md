# Glossary

One file per term. Each term is defined here once and linked from everywhere else.

| Term | Summary |
| --- | --- |
| [Occurrence](occurrence.md) | One lecture on one specific date. |
| [Ticket](ticket.md) | A change request in the lecture-rescheduling module, modelled on a GitHub pull request. |
| [Conflict](conflict.md) | A rule violation found while checking a ticket, the equivalent of a merge conflict. |
| [Self-approval](self-approval.md) | The author applies their own ticket without any reviewer. |
| [Issue](issue.md) | A request opened by a CR or BR, modelled on a GitHub issue. |
| [Lecture mode](lecture-mode.md) | Whether a lecture is held in person or online. |
