A shared backend package that provides a capability genuinely used across [features](feature.md), such as API conventions, security conventions, configuration, observability or auditing support. It must stay narrowly defined and must not collect unrelated classes or business logic. See [layers and boundaries](../../architecture/layers-and-boundaries.md).
