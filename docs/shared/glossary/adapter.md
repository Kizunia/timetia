# Adapter

- **Type:** reference
- **Module:** shared
- **Status:** draft
- **Owner:** ishanKulkarni13
- **Last updated:** 2026-10-27

> **Implementation:** not applicable (definition).

Infrastructure code that implements a [port](port.md): for example a class that talks to the database or an external system on behalf of application logic. Adapters may depend on frameworks and vendor libraries; application logic may not depend on adapters. See [hexagonal architecture](hexagonal-architecture.md).
