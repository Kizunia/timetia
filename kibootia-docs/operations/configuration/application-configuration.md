# Application Configuration

- **Type:** spec
- **Module:** platform
- **Status:** draft
- **Owner:** ishanKulkarni13
- **Last updated:** 2026-11-10

> **Implementation:** partly observed. No secret is in version control, `.env.example` and `pnpm bootstrap` exist, and a missing required setting stops startup with a message naming it. Typed `kibootia.*` configuration classes and the production "no development defaults" guard do not exist yet. No CI run yet.

## Principles (owner decisions)

- Local development uses environment variables and Docker Compose.
- Production secrets arrive as environment variables or mounted files; Vault is a recommended source ([secrets management](../security/secrets-management.md), [ADR 0032](../../decisions/0032-secrets-from-environment-and-files.md)).
- Configuration is typed and validated where practical. A missing required setting fails startup clearly.
- Production never silently falls back to development values; startup fails if it detects development defaults.
- Local secrets are generated per developer from a safe example environment file, and real values are never committed.
- Each infrastructure-backed module has an on/off property ([ADR 0024](../../decisions/0024-package-modules-with-infrastructure-toggles.md)).

## Naming (owner decision of 2026-11-08)

- Kibootia's own settings are named `kibootia.<module>.<setting>` and bound to typed configuration classes with validation. A missing or invalid required setting stops startup with a message naming the setting.
- Module switches are `kibootia.<module>.enabled` and exist only for infrastructure-backed modules ([ADR 0024](../../decisions/0024-package-modules-with-infrastructure-toggles.md)).
- Environment variables follow Spring Boot's relaxed binding: `kibootia.files.max-upload-size` is set by `KIBOOTIA_FILES_MAX_UPLOAD_SIZE`.
- Standard Spring Boot settings keep their own names (for example `SPRING_DATASOURCE_URL`).
- Local values come from the root `.env`, created by `pnpm bootstrap` with generated secrets ([ADR 0040](../../decisions/0040-local-development-topology-and-setup.md)). `.env.example` lists every variable with safe placeholders.

| Retention | Audit retention (default 365 days), soft-delete retention (default 30 days) | None |
| Management | Management port for health ([ADR 0047](../../decisions/0047-health-exposure-and-container-images.md)) | None |
