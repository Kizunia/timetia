# Capability tier

- **Type:** reference
- **Module:** shared
- **Status:** draft
- **Owner:** ishanKulkarni13
- **Last updated:** 2026-10-28

> **Implementation:** not applicable (definition).

How a capability is shipped: core (always present), default-on (ships and runs, removable), optional (ships, off until enabled), recipe (documentation only) or future. The tiers are used in the [technology catalogue](../../technology/README.md). Decision: [ADR 0024](../../decisions/0024-package-modules-with-infrastructure-toggles.md).
