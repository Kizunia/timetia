# Resource Server

- **Type:** reference
- **Module:** shared
- **Status:** draft
- **Owner:** ishanKulkarni13
- **Last updated:** 2026-10-27

> **Implementation:** not applicable (definition).

In OAuth 2.0 terms, a backend API that does not log users in itself but accepts and validates bearer access tokens issued by an identity provider (Keycloak). Kibootia's backend is a resource server: [ADR 0007](../../decisions/0007-spring-security-resource-server.md).
