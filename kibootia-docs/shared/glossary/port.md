# Port

- **Type:** reference
- **Module:** shared
- **Status:** draft
- **Owner:** ishanKulkarni13
- **Last updated:** 2026-10-27

> **Implementation:** not applicable (definition).

An interface owned by application logic that describes a capability it needs (for example, storing or loading something). It is implemented by an [adapter](adapter.md). Ports are introduced when a boundary is useful, not for every class. See [hexagonal architecture](hexagonal-architecture.md).
