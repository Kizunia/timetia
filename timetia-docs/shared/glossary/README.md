# Glossary

One file per term. Each term is defined here once and linked from everywhere else.

| Term | Summary |
| --- | --- |
| [Occurrence](occurrence.md) | One lecture on one specific date. |
| [Ticket](ticket.md) | A change request in the lecture-rescheduling module, modelled on a GitHub pull request. |
| [Conflict](conflict.md) | A rule violation found while checking a ticket, the equivalent of a merge conflict. |
| [Self-approval](self-approval.md) | The author applies their own ticket without any reviewer. |
| [Issue](issue.md) | A request opened by a CR or BR, modelled on a GitHub issue. |
| [Lecture mode](lecture-mode.md) | Whether a lecture is held in person or online. |
| [Timetable](timetable.md) | The weekly schedule of a division for a semester, versioned (for example V1, W.E.F. |
| [Timetable entry](timetable-entry.md) | One session in the timetable: faculty, subject, division or batch, session type, room, day and slot(s). |
| [Slot](slot.md) | One hourly cell in the grid, Monday to Friday, 08:00 to 20:00. |
| [Session type](session-type.md) | Theory (1 slot), Lab (2 consecutive slots, one batch) or Tutorial (1 slot, one batch). |
| [Division](division.md) | A class, for example SY-CSSE-B. |
| [Batch](batch.md) | A sub-group of a division for labs and tutorials, for example B1 to B5. |
| [Change overlay](change-overlay.md) | The set of applied changes this module stores on top of the base timetable. |
| [CR (class representative)](class-representative.md) | A student representative of a division. |
| [BR (batch representative)](batch-representative.md) | A student representative of a batch. |
