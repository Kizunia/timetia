# Supported change types

- **Type:** spec
- **Module:** lecture-rescheduling
- **Status:** draft
- **Owner:** ishanKulkarni13
- **Last updated:** 2026-11-06

Migrated from the original [spec](../_archive/original-spec.md), sections 2, 4, 5 and 9.

The module supports reschedule, exchange, extra lecture, cancel and substitute, each working on one dated [occurrence](../../../shared/glossary/occurrence.md) by default. Permanent changes go through the HOD. See [change types](../../../shared/enums/change-types.md).
