# Context and boundaries

- **Type:** reference
- **Module:** platform
- **Status:** draft
- **Owner:** ishanKulkarni13
- **Last updated:** 2026-11-06

**Version 1 is standalone.** The system owns its base timetable, users, roles, rooms, calendar, tickets, change overlay, notifications and audit log. All base data is seeded manually. There is no ERP sync.

A webhook or similar integration with the ERP (EduPlusCampus) is expected later. The intended split of ownership then is in [ERP ownership](../modules/lecture-rescheduling/integration/erp-ownership.md). Decision: [0001](../modules/lecture-rescheduling/decisions/0001-standalone-version-1.md).
